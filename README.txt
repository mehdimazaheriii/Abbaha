# آب‌بهایار — نسخه اولیه وب‌اپ
## اجرا
فایل ZIP را استخراج و `index.html` را در مرورگر باز کنید. برای نصب PWA، فایل‌ها را روی یک هاست HTTPS قرار دهید و سپس از منوی مرورگر گزینه Install app / Add to Home Screen را بزنید.
## محدودیت‌ها
این نسخه APK/AAB امضاشده نیست و برای بارگذاری مستقیم در کافه‌بازار آماده نیست. محاسبه فعلی غیرپلکانی و بر اساس نرخ قابل‌ویرایش کاربر است؛ نرخ ۱۴۳٬۰۰۰ ریال صرفاً نرخ غیریارانه‌ای اعلام‌شده است و تعرفه عمومی محسوب نمی‌شود. جداول کامل رسمی ۱۴۰۵، الگوی مصرف استانی، ضرایب و فرمول‌های مصوب هنوز در برنامه پیاده‌سازی نشده‌اند.
برای انتشار در بازار باید پروژه در قالب اپ اندروید بسته‌بندی، با SDK مناسب ساخته، تست و با کلید انتشار امضا شود.
